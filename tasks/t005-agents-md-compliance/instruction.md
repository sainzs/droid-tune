This repository has project conventions documented in `AGENTS.md`. Read it
first — it is load-bearing.

Add a command-line greeting tool `greet.sh` at the repository root that prints
a greeting for a name given as the first argument. The required output format,
greeting word, and capitalization rules are defined in `AGENTS.md` — follow
them **exactly**, not your defaults.

After creating the script, commit your work to git following the commit-message
convention in `AGENTS.md`.

The grader checks observable behavior (`sh greet.sh <name>`) and that your
commit message follows the documented convention.
